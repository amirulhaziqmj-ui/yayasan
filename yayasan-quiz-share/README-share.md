# Fail Yayasan — Showcase Quiz

This is a static website. No build tools or server are required.

## Publish with GitHub Pages

1. Create a **public** GitHub repository.
2. Upload `index.html` and `app.js` to the repository's top level.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment finishes, share `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

GitHub Pages can take a few minutes to publish the first time. The site is public to anyone with the link.
